# Open Source Models

> 分类：**工具与生态** → **Open Source Models**
> 路径：`resources/knowledge/11-tools-ecosystem/open-source-models`

本目录用于存放与「Open Source Models」相关的学习资料。

## 收录范围

- 教材与讲义（Markdown / PDF）
- 论文（PDF）
- 讲稿与笔记（Markdown / Word / PPTX）

## 命名约定

- 每个子主题一个文件夹，文件夹命名用 kebab-case。
- 每个文件夹下放一个 `_index.md` 作为目录索引（阶段 2 由索引生成器读取）。
- 文件名建议：`YYYY-MM-DD-<title>.md` 或原文件名。
