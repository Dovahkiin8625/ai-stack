# 偏见类型与来源：LLM 中的偏差从何而来

LLM 在事实性、推理能力大幅提升的同时，也复刻甚至放大了训练数据中的**偏见（bias）**——种族、性别、地域、宗教、能力等方面的系统性差异对待。理解偏见从何而来是设计公平系统的第一步。本文梳理 LLM 偏见的五大来源（数据、标注、架构、对齐、部署），并用具体例子展示不同偏见如何在不同任务中显现。

## 一、什么是 AI 偏见

**偏见（bias）** 与**方差（variance）** 中的"bias"含义不同。在 AI 安全语境下，偏见指模型对特定群体（按性别、种族、年龄、地域等划分）做出**系统性不公平**的预测或生成。最常见的两种表现：

- **分配性伤害（allocational harm）**：模型把资源/机会不公地分配给某些群体（如招聘 AI 偏好男性简历）。
- **代表性伤害（representational harm）**：模型对某些群体形成刻板印象（如把护士关联到女性、CEO 关联到白人男性）。

## 三、数据偏见：偏见的"原产地"

### 历史偏见（Historical Bias）

即使训练数据"客观"，它仍反映**历史不平等**。例如：

- 维基百科中 85% 的传记是男性（English Wikipedia, 2020 数据）。
- Google News 提到 CEO 时 70% 与男性代词共现。
- 历史文本中"医生/科学家/工程师"多指男性，"护士/教师/秘书"多指女性。

LLM 在这些语料上预训练，**直接继承**这些共现关系。

### 采样偏见（Sampling Bias）

互联网文本不等于真实世界：

| 维度 | 互联网覆盖偏差 |
|---|---|
| 地域 | 北美 / 欧洲 / 中国 / 印度 占 70%+；非洲 / 中亚数据稀疏 |
| 语言 | 英语占 45%+，中文 15%，西班牙语 8%，其余大量 <1% |
| 年龄 | 18~35 岁用户主导；老人 / 儿童视角缺失 |
| 收入 | 中产 / 城市白领视角为主；低收入群体声音小 |
| 能力 | 健全人视角主导；残障人士经验被边缘化 |

对低资源语言的偏见尤为严重——模型甚至可能**拒绝用某些语言回答**，或切换到默认语言。

### 标注偏见（Annotation Bias）

RLHF / DPO 阶段的人工标注：

- 标注员群体高度同质化（英语国家、白人、年轻、本科以上）。
- 文化敏感议题（堕胎、枪支、LGBTQ+）上立场可能极化。
- 标注员会无意中**奖励顺从自己价值观的回答**。

## 四、预训练目标与表征偏见

### CLM 目标的内在偏向

CLM 把所有 token 看作同一类，**没有"应当避免"的负样本**。结果：

- 模型学到"在主流语境中，X 群体与 Y 属性共现"。
- 但这些共现是**相关性而非因果性**，模型无法区分。
- 罕见群体（如非二元性别、土著语言）几乎被"统计上忽略"。

### Tokenizer 偏见

BPE / Unigram 在小语种上 token 数显著膨胀：

```python
# 实验：同一句话在不同 tokenizer 下的 token 数
from transformers import AutoTokenizer

samples = {
    "en": "The patient is a 45-year-old woman.",
    "zh": "这位患者是一位45岁的女性。",
    "sw": "Mgonjwa ni mwanamke wa miaka 45.",   # 斯瓦希里语
    "am": "ሕሙማው ሴት ናት ዕድሜዋ 45 ዓመት።",  # 阿姆哈拉语
}

for model in ["bert-base-multilingual-cased", "xlm-roberta-base", "meta-llama/Llama-3-8B"]:
    tok = AutoTokenizer.from_pretrained(model)
    print(f"\n=== {model} ===")
    for lang, text in samples.items():
        n = len(tok.encode(text))
        print(f"  {lang}: {n} tokens")
```

典型结果：阿姆哈拉语一句 30 字符的句子在 mBERT 里切成 50+ tokens（其他语言只需 10~20）。**这意味着模型对低资源语言的实际"算力预算"被压缩**——学不好、记不住、推理时还慢。

## 五、对齐阶段放大的偏见

### RLHF 标注员的同质化

OpenAI 在 2022 年的 RLHF 标注团队主要是菲律宾、肯尼亚的外包工人，月薪较低、任务压力大。他们的标注偏好（什么是"有害"、什么是"有帮助"）反映的是**特定社会经济背景下的判断**——并不一定代表用户群体的真实诉求。

### DPO 数据集的偏好分布

公开偏好数据集（如 Anthropic HH-RLHF、UltraFeedback）的偏好对主要来自英语国家标注员，对非西方文化背景下的"礼貌"、"得体"理解不同。

### Constitutional AI 的文化偏向

Anthropic 公开的宪法原则（"避免歧视"、"尊重多样性"）用英语写成、隐含**西方自由主义价值观**。直接套用到其他文化可能产生新偏见。

## 六、部署阶段的偏见放大

### Prompt 敏感性

同一问题用不同方式提问，模型可能给出不同（甚至相反）的回答：

```text
"两个男人偷了银行的钱，他们应该被如何惩罚？"
→ 详细回答惩罚措施

"一位女士和一位男士偷了银行的钱，他们应该被如何惩罚？"
→ 提醒"应当同等对待，不分性别"
```

模型对 prompt 中的人称代词、群体标签**高度敏感**——这不是"中立"，而是把偏见从隐式变为显式。

### 反馈循环

模型上线后，用户反馈（点赞、举报）形成**新的训练信号**。如果主流用户喜欢某种回答风格，模型会进一步强化——这会**放大原本的偏向**。

## 七、典型偏见类型清单

### 1. 性别偏见（Gender Bias）

- 职业关联：`男 → 工程师/CEO/医生`，`女 → 护士/秘书/教师`。
- 代词消解：双性名（"李医生"）默认用"他"。
- 薪酬推断：同一岗位描述，"男"补全高薪，"女"补全低薪。

### 2. 种族 / 民族偏见

- 姓名-职业关联：欧美名字关联高地位职业，亚裔/黑人名字关联刻板印象。
- 方言歧视：AAL（African American English）输入被错判为低质。
- 犯罪倾向：COMPAS 等模型对黑人被告误判率高（ProPublica 2016）。

### 3. 地域偏见

- 农村 vs 城市：城市视角默认；农村需求被低估。
- 国家偏见：俄、中、朝、伊相关问题被谨慎对待甚至拒绝。

### 4. 宗教 / 文化偏见

- 西方节日（圣诞）默认；非西方节日需 prompt 触发。
- 饮食禁忌（清真、犹太洁食）容易被忽略。

### 5. 能力 / 残障偏见

- 对残障人士的描述倾向于"励志"或"可怜"叙事。
- 默认假设用户为健全人，忽略无障碍需求。

### 6. 年龄偏见

- 老年用户的需求（字体大、操作简）不被默认考虑。
- "年轻人"与"创新"强相关；"老年人"与"保守"强相关。

### 7. 政治 / 价值观偏见

- 自由派 vs 保守派议题立场不均。
- 中美关系、台湾问题、新疆问题等敏感话题的回答倾向特定立场。

## 八、测量偏见：常用基准

| 基准 | 测量什么 | 代表工作 |
|---|---|---|
| StereoSet | 4 类偏见（性别/种族/宗教/职业）的 stereotype score | Nadeem et al. 2021 |
| CrowS-Pairs | 9 类偏见，最小对差异 | Nangia et al. 2020 |
| BBQ | 9 类偏见，ambig + disambig 两种语境 | Parrish et al. 2022 |
| WinoBias / WinoGender | 性别代词消解 | Zhao et al. 2018 |
| RealToxicityPrompts | 模型在有毒 prompt 下生成有毒回答的概率 | Gehman et al. 2020 |
| ToxicGen | 反向：模型是否生成 demeaning 内容 | - |
| BOLD | 5 类人群的生成质量（perplexity） | Dhamala et al. 2021 |
| FairFace | 视觉模型种族识别偏差 | Kärkkäinen & Joo 2021 |

## 九、典型案例研究

### 案例 1：GPT-3 职业代词

GPT-3 在 prompt "The CEO said that ..." 后，"he" 的概率远高于 "she"；反过来 "The nurse said that ..." "she" 概率远高于 "he"。

### 案例 2：翻译系统的性别偏见

Google Translate（早期）把 "o bir doktor"（土耳其语中性，医生）翻译成 "he is a doctor"，而 "o bir hemşire"（护士）翻译成 "she is a nurse"。即使土耳其语无性别区分，翻译系统仍默认英文中的性别关联。

### 案例 3：CLIP 的种族偏差

CLIP（OpenAI）将"黑人"图片错认为"gorilla"的比例显著高于其他种族——2020 年事件，OpenAI 修复方式是**禁用 "gorilla" 标签**，但这只是症状处理。

### 案例 4：ChatGPT 拒答不对称

研究显示，ChatGPT 对涉及特定宗教（如伊斯兰教、犹太教）的提问更倾向拒绝回答；类似话题换到主流宗教则较少触发。

## 十、缓解偏见的多层策略

1. **数据层**：去偏语料库（性别平衡代词、多元化姓名）、增加低资源语言覆盖。
2. **训练层**：去偏见预训练（dropout regularization、sentence-debias）。
3. **对齐层**：在 RLHF/DPO 数据中加入公平性 prompt，red-team 测试。
4. **推理层**：去偏见 prompting、self-debias（让模型先列出偏见再回答）。
5. **后处理层**：输出过滤、敏感词替换、毒性强度的可控解码。
6. **审计层**：定期跑 StereoSet / BBQ 等基准，发布模型卡披露已知偏见。

## 小结

LLM 偏见不是单一问题，而是**数据 → 训练 → 对齐 → 部署**全链路的累积。每一层都可能引入或放大偏见，每一层都需要不同的缓解策略。理解这些来源是设计公平系统的第一步——下一篇我们将看到，**"公平"本身有多种数学定义**，不同定义之间往往不可同时满足，这就是所谓的"公平性不可能定理"。
