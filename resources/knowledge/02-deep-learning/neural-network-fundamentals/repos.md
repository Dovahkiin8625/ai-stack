# 开源仓库：神经网络基础组件

## PyTorch

- 仓库：https://github.com/pytorch/pytorch
- 简介：张量计算 + 自动微分框架，是当前学术与工业最主流的深度学习实现平台；包含 nn.Module、autograd、CUDA 后端与分布式训练原语。
- 适用：几乎所有研究 / 生产模型的基座。

## tinygrad

- 仓库：https://github.com/geohot/tinygrad
- 简介：George Hotz 维护的极简深度学习框架（约 1 万行代码），目标是「可读、可改、可学习」。源码本身是一份高质量的神经网络基础教程。
- 适用：想从零理解自动微分、算子调度、LazyBuffer 机制的读者。

## labml.ai / annotated_deep_learning_paper_implementations

- 仓库：https://github.com/labmlai/annotated_deep_learning_paper_implementations
- 简介：带逐行注释的论文复现集合，覆盖反向传播、BatchNorm、Dropout、LayerNorm、Transformer、Diffusion 等基础组件。
- 适用：用「读论文 + 看代码」的方式吃透基础算法。
