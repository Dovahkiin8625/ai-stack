# 开源仓库：语音合成（TTS）

## Coqui TTS

- 仓库：https://github.com/coqui-ai/TTS
- 简介：覆盖 Tacotron2 / VITS / XTTS / Glow-TTS / StyleTTS2 等数十种 TTS 模型的统一库，配套训练 / 推理 / WebUI。
- 适用：多语种合成、声音克隆、研究与生产。

## ESPnet

- 仓库：https://github.com/espnet/espnet
- 简介：日本主导的端到端语音处理工具包，涵盖 ASR / TTS / ST / SSL，提供 Joint training 与 recipe 生态。
- 适用：研究实验、可复现论文 recipe。

## VITS / VITS2 复现

- 仓库：https://github.com/jaywalnut310/vits
- 简介：论文 *Conditional Variational Autoencoder with Adversarial Learning for End-to-End Text-to-Speech* 官方实现。
