# 开源仓库：音频 / 音乐生成

## AudioCraft (Meta)

- 仓库：https://github.com/facebookresearch/audiocraft
- 简介：MusicGen / AudioGen / EnCodec 的官方实现库，覆盖音乐 / 音效生成。

## AudioLDM / AudioLDM 2

- 仓库：https://github.com/haoheliu/AudioLDM
- 简介：*AudioLDM: Text-to-Audio Generation with Latent Diffusion Models* 官方实现，支持音效 / 语音 / 音乐生成。

## Bark (Suno)

- 仓库：https://github.com/suno-ai/bark
- 简介：完全开源的多语种 Transformer TTS，支持笑声 / 叹息 / 非语言声音。

## RVC (Retrieval-based Voice Conversion)

- 仓库：https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI
- 简介：基于检索的轻量级声音转换 / 翻唱工具，社区生态活跃。
