# 开源仓库：文本表示

## sentence-transformers

- 仓库：https://github.com/UKPLab/sentence-transformers
- 简介：在 BERT / RoBERTa 之上构建句向量，支持 100+ 预训练模型，提供 SBERT/SBERT-multilingual 训练脚本。
- 适用：语义检索、聚类、句子相似度。

## fastText

- 仓库：https://github.com/facebookresearch/fastText
- 简介：Facebook 出品的子词级词向量 + 文本分类库，训练与推理速度极快，多语言支持。
- 适用：百万级语料训练、轻量级分类。

## gensim

- 仓库：https://github.com/piskvorky/gensim
- 简介：经典主题建模 / 词向量库，提供 Word2Vec / Doc2Vec / FastText / LDA / NMF 实现。
- 适用：教学、LDA/word2vec 实验。
