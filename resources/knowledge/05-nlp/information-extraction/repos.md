# 开源仓库：信息抽取

## UIE / DeepKE

- 仓库：https://github.com/zjunlp/DeepKE
- 简介：浙江大学开源的知识抽取工具包，覆盖 NER / RE / 属性抽取，论文 UIE 的官方实现。
- 适用：结构化知识抽取、学术基准。

## OpenNRE

- 仓库：https://github.com/thunlp/OpenNRE
- 简介：清华 THUNLP 出品的关系抽取工具包，支持有监督 / 远程监督 / few-shot 关系抽取。

## spaCy + spacy-relation-extractor

- 仓库：https://github.com/explosion/spaCy
- 简介：spaCy 生态可扩展工业级 IE 流水线。

## REBEL / REBEL-spacy

- 仓库：https://github.com/Babelscape/rebel
- 简介：Babelscape 提出的端到端关系抽取（seq2seq），可直接从文本生成关系三元组。
