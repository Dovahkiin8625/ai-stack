# 开源仓库：文本生成

## Hugging Face Transformers

- 仓库：https://github.com/huggingface/transformers
- 简介：通用 seq2seq / Causal LM 库，支持 GPT-2 / T5 / BART / LLaMA 等训练与推理，`generate()` 接口覆盖 greedy / beam / sampling / contrastive。

## fairseq

- 仓库：https://github.com/facebookresearch/fairseq
- 简介：Meta 出品的 seq2seq 工具包，原始实现 BART / mBART / 非自回归生成等模型。

## Text Generation WebUI (oobabooga)

- 仓库：https://github.com/oobabooga/text-generation-webui
- 简介：开箱即用的 LLM 推理 UI，支持 LoRA / 多种后端（transformers / llama.cpp / ExLlamaV2）。
- 适用：本地交互式测试、多模型对比。
