# 开源仓库：机器翻译

## fairseq

- 仓库：https://github.com/facebookresearch/fairseq
- 简介：seq2seq 翻译经典工具包，支持 Transformer / Convolutional seq2seq / multilingual NMT。

## OpenNMT-py

- 仓库：https://github.com/OpenNMT/OpenNMT-py
- 简介：PyTorch 实现的通用 NMT 框架，覆盖训练/推理/服务全流程。

## Marian (Helsinki-NLP / Hugging Face)

- 仓库：https://github.com/Helsinki-NLP/Opus-MT
- 简介：Helsinki-NLP 出品的高效 C++ 训练栈 + 上千种预训练 Opus-MT 模型；通过 HuggingFace `MarianMTModel` 一行加载。
- 适用：开箱即用的多语言翻译。

## EasyNMT

- 仓库：https://github.com/UKPLab/EasyNMT
- 简介：基于 Opus-MT / M2M100 的易用翻译 API。
