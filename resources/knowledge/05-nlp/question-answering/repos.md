# 开源仓库：问答系统

## Haystack (deepset)

- 仓库：https://github.com/deepset-ai/haystack
- 简介：端到端 QA / RAG 框架，支持抽取式 QA（基于 SQuAD 微调的 Reader）、检索式 QA、多文档问答。
- 适用：企业知识库、文档问答。

## Hugging Face Transformers (Question Answering)

- 仓库：https://github.com/huggingface/transformers
- 简介：内置 Extractive QA pipeline，兼容 SQuAD 格式数据。

## LangChain + LlamaIndex

- 仓库：https://github.com/langchain-ai/langchain ｜ https://github.com/run-llama/llama_index
- 简介：用 RAG 框架做生成式 QA，搭配向量库实现知识库问答。

## DrQA (Facebook Research)

- 仓库：https://github.com/facebookresearch/DrQA
- 简介：经典开放域 QA 系统（文档检索 + 阅读理解），论文 *Reading Wikipedia to Answer Open-Domain Questions* 官方实现。
