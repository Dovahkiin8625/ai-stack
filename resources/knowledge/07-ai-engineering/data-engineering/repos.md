# 开源仓库：数据工程

## Hugging Face Datasets

- 仓库：https://github.com/huggingface/datasets
- 简介：百万级数据集统一加载 API，支持流式 / Arrow 后端 / 多模态；HuggingFace Hub 上 10w+ 数据集一键加载。
- 适用：训练数据准备、benchmark 加载。

## Apache Arrow / Parquet

- 仓库：https://github.com/apache/arrow
- 简介：列式内存数据格式，跨语言零拷贝；现代数据栈（Spark/Pandas/Polars/DuckDB）的共同底层。

## Polars

- 仓库：https://github.com/pola-rs/polars
- 简介：Rust 编写的 DataFrame 库，10–100× 优于 Pandas；适合大规模数据预处理。

## DuckDB

- 仓库：https://github.com/duckdb/duckdb
- 简介：进程内 OLAP 数据库，原生支持 Parquet/CSV/JSON 直接查询；本地数据湖分析利器。

## Label Studio

- 仓库：https://github.com/HumanSignal/label-studio
- 简介：开源数据标注平台，支持文本/图像/音频/视频多模态标注与多人协作。
