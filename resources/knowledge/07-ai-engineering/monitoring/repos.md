# 开源仓库：ML 监控与可观测性

## Evidently AI

- 仓库：https://github.com/evidentlyai/evidently
- 简介：开源 ML / LLM 监控与评估平台，支持 data drift / model drift / data quality / LLM eval；含可视化 dashboard。

## Grafana + Prometheus

- 仓库：https://github.com/grafana/grafana ｜ https://github.com/prometheus/prometheus
- 简介：通用指标监控与可视化组合；ML 服务部署到 K8s 后通常用其监控 QPS / 延迟 / GPU 利用率 / 显存等。

## LangSmith (LangChain)

- 仓库：https://github.com/langchain-ai/langchain
- 简介：LangChain 推出的 LLM 应用可观测性平台；提供 trace / eval / dataset 管理。

## Phoenix (Arize)

- 仓库：https://github.com/Arize-ai/phoenix
- 简介：开源 LLM / CV 可观测性平台，支持 embedding 可视化、drift、retrieval 评估。

## whylogs

- 仓库：https://github.com/whylabs/whylogs
- 简介：轻量级数据 / 模型 profile 库，记录数据分布用于离线/在线 drift 检测。
