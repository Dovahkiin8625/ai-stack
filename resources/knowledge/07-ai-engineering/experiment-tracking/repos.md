# 开源仓库：实验追踪与可观测性

## MLflow

- 仓库：https://github.com/mlflow/mlflow
- 简介：开源 MLOps 平台，覆盖实验追踪 / 模型注册 / 项目打包 / 模型部署四大模块；与 PyTorch / sklearn / xgboost 深度集成。
- 适用：团队级实验管理。

## Weights & Biases

- 仓库：https://github.com/wandb/wandb
- 简介：SaaS + 开源自托管的实验追踪工具，可视化、超参搜索（sweeps）、artifact 存储、模型 registry。
- 适用：研究协作、报表可视化。

## TensorBoard

- 仓库：https://github.com/tensorflow/tensorboard
- 简介：TensorFlow 自带的可视化工具，现已通用化；支持 loss / graph / histogram / image / embedding / profiler。

## DVC (Data Version Control)

- 仓库：https://github.com/iterative/dvc
- 简介：Git for data & models，支持数据/模型版本化、pipeline、远程存储（S3/GDrive/SSH）。

## Aim

- 仓库：https://github.com/aimhubio/aim
- 简介：开源实验追踪 UI，3 万条实验秒级查询；自托管、对标 W&B。
