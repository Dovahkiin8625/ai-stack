# 开源仓库：Tool Use

## LangChain Tools

- 仓库：https://github.com/langchain-ai/langchain
- 简介：内置数百种 Tool（搜索 / SQL / Python / 文件 / API），统一 `BaseTool` 抽象，便于扩展。

## LlamaIndex Tooling

- 仓库：https://github.com/run-llama/llama_index
- 简介：把 FunctionTool / QueryEngineTool / ToolSpec 作为 agent 可调用单元；与 OpenAI Function Calling 兼容。

## Gorilla (Berkeley)

- 仓库：https://github.com/ShishirPatil/gorilla
- 简介：*Gorilla: Large Language Model Can Connect 600+ APIs* 官方实现与数据集，覆盖 600+ API 的检索增强调用。

## ToolBench / ToolLLaMA

- 仓库：https://github.com/OpenBMB/ToolBench
- 简介：*ToolLLM* / *APIBank* 项目工具增强训练的官方数据 + 训练代码，构造大规模工具调用场景。

## Composio

- 仓库：https://github.com/ComposioHQ/composio
- 简介：聚合 250+ SaaS API（GitHub / Slack / Notion / Gmail 等） 的统一工具层，供 agent 一键接入。
