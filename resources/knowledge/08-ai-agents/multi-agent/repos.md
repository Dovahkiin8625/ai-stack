# 开源仓库：Multi-Agent 协作

## Microsoft AutoGen

- 仓库：https://github.com/microsoft/autogen
- 简介：多 Agent 对话框架；支持可定制的角色 (AssistantAgent / UserProxyAgent)、群聊 (GroupChat) 与人类参与循环。

## CrewAI

- 仓库：https://github.com/crewAIInc/crewAI
- 简介：以「角色 → 任务 → 团队 (Crew)」为主线的多 Agent 编排框架；流程 (Process) 支持 sequential / hierarchical。

## LangGraph

- 仓库：https://github.com/langchain-ai/langgraph
- 简介：用图表达 multi-agent 工作流，原生支持循环、状态持久化、人在环监督。

## OpenAI Swarm (实验性)

- 仓库：https://github.com/openai/swarm
- 简介：OpenAI 出的轻量 multi-agent 编排示例，强调「handoff」概念。

## ChatDev (虚拟软件公司)

- 仓库：https://github.com/OpenBMB/ChatDev
- 简介：*Communicative Agents for Software Development* 官方实现，多个 LLM agent 模拟软件公司各角色（CEO / CTO / Programmer / Tester）协作完成项目。
