# 开源仓库：Agent 架构

## LangChain Agents

- 仓库：https://github.com/langchain-ai/langchain
- 简介：LangChain 内置多种 Agent 范式（ReAct / OpenAI Functions / Structured Chat / Plan-and-Execute），统一 Tool / Memory / Chain 抽象。

## AutoGPT

- 仓库：https://github.com/Significant-Gravitas/AutoGPT
- 简介：*Autonomous GPT-4 experiment* 的代表实现，展示 LLM 自主循环（规划、执行、自我批评）。

## BabyAGI

- 仓库：https://github.com/yoheinakajima/babyagi
- 简介：极简的 Task-Driven Autonomous Agent，使用向量库 + LLM 形成任务创建 / 优先级排序 / 执行循环。

## smolagents (Hugging Face)

- 仓库：https://github.com/huggingface/smolagents
- 简介：HF 出品的轻量级 Agent 库，主打 Code Agent（让 LLM 直接写 Python 而非 JSON 调用工具）。
