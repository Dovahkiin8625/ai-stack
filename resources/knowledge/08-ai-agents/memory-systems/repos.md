# 开源仓库：Agent 记忆系统

## Letta (MemGPT 团队)

- 仓库：https://github.com/letta-ai/letta
- 简介：MemGPT 论文 *MemGPT: Towards LLMs as Operating Systems* 的官方实现，提供分层内存（core memory / archival memory / recall），支持自托管与 OpenAI 兼容 API。

## mem0

- 仓库：https://github.com/mem0ai/mem0
- 简介：可插拔的 LLM 长期记忆层，提取对话事实 + 向量检索，支持本地或托管模式。
- 适用：个性化 chatbot 持久记忆。

## LangChain Memory

- 仓库：https://github.com/langchain-ai/langchain
- 简介：内置多种 Memory（ConversationBufferMemory / SummaryMemory / VectorStoreMemory），可与 LangGraph 组合实现工作流级记忆。

## Zep (Chat History)

- 仓库：https://github.com/getzep/zep
- 简介：面向对话应用的长期记忆服务，自动摘要、事实提取、相关性检索；提供 REST API。
