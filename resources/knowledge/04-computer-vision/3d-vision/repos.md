# 开源仓库：3D 视觉

## nerfstudio

- 仓库：https://github.com/nerfstudio-project/nerfstudio
- 简介：模块化的 NeRF 框架，统一 Nerfacto / Instant-NGP / Gaussian Splatting 等实现，含可视化与数据加载工具。
- 适用：NeRF 入门研究、3D 重建。

## gaussian-splatting (INRIA)

- 仓库：https://github.com/graphdeco-inria/gaussian-splatting
- 简介：*3D Gaussian Splatting for Real-Time Radiance Field Rendering* 官方实现，渲染速度远超 NeRF。
- 适用：实时 3D 重建、场景捕获。

## Open3D

- 仓库：https://github.com/isl-org/Open3D
- 简介：3D 数据处理库（点云 / 三角网格 / RGBD），含 ICP / 配准 / 可视化。
- 适用：3D 数据预处理、点云算法。

## PyTorch3D (Meta)

- 仓库：https://github.com/facebookresearch/pytorch3d
- 简介：可微分 3D 渲染与几何操作库，用于 3D 深度学习（NeRF、3D 重建）。
