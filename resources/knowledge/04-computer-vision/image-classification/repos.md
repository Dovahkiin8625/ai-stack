# 开源仓库：图像分类

## timm (pytorch-image-models)

- 仓库：https://github.com/huggingface/pytorch-image-models
- 简介：超过 700 种骨干实现，ResNet/EfficientNet/ConvNeXt/Swin/ViT 全部覆盖；包含训练 recipe 与 ImageNet 预训练权重。
- 适用：选型、迁移学习、消融实验。

## torchvision

- 仓库：https://github.com/pytorch/vision
- 简介：PyTorch 官方视觉库，分类模型 + 数据集 + 标准化 transform；适合做 baseline。

## MMPreTrain

- 仓库：https://github.com/open-mmlab/mmpretrain
- 简介：OpenMMLab 预训练框架，覆盖 50+ 骨干 + 多种训练配方（监督、MAE、DINO 等）。
