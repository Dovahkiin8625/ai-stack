# 开源仓库：目标检测

## Ultralytics YOLO

- 仓库：https://github.com/ultralytics/ultralytics
- 简介：YOLOv5 / YOLOv8 / YOLO11 官方实现，一行命令训练/推理/导出（ONNX/TensorRT/CoreML）。
- 适用：实时检测、端侧部署、工业产线。

## detectron2 (Meta)

- 仓库：https://github.com/facebookresearch/detectron2
- 简介：Meta 出品的检测/分割框架，原始实现 Faster R-CNN / Mask R-CNN / RetinaNet / DETA 等。
- 适用：研究级实验、自定义检测头。

## MMDetection (OpenMMLab)

- 仓库：https://github.com/open-mmlab/mmdetection
- 简介：模块化检测框架，集成 70+ 模型（Faster R-CNN / DETR / DINO / RTMDet 等），训练配置可组合。
- 适用：算法选型、消融、多模型对比。

## RT-DETR (Baidu)

- 仓库：https://github.com/lyuwenyu/RT-DETR
- 简介：实时 DETR 系列，去除 NMS 的端到端检测器，论文 *DETRs Beat YOLOs on Real-time Object Detection*。
