# 开源仓库：图像分割

## Segment Anything (Meta)

- 仓库：https://github.com/facebookresearch/segment-anything
- 简介：SAM / SAM2 官方实现，零样本分割 + promptable mask；SAM2 扩展到视频。
- 适用：通用分割、数据标注预训练。

## MMSegmentation (OpenMMLab)

- 仓库：https://github.com/open-mmlab/mmsegmentation
- 简介：模块化分割框架，集成 U-Net / DeepLab / Mask2Former / SegFormer 等几十种模型。
- 适用：语义/实例分割研究、benchmark。

## detectron2 (Meta)

- 仓库：https://github.com/facebookresearch/detectron2
- 简介：Mask R-CNN / PointRend 等实例分割官方实现。

## YOLO-Seg (Ultralytics)

- 仓库：https://github.com/ultralytics/ultralytics
- 简介：YOLOv8-seg 提供实例分割能力，结合 detection + segmentation 一体化训练。
