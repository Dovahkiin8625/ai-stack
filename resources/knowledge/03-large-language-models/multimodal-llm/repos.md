# 开源仓库：多模态 LLM

## LLaVA

- 仓库：https://github.com/haotian-liu/LLaVA
- 简介：Visual Instruction Tuning 的代表工作，把 CLIP ViT 与 LLaMA 通过一个投影层 + SFT 串起来；提供 1.5 / 1.6 / OneVision 等系列。
- 适用：图像-文本对话、视觉问答、屏幕/UI 理解。

## OpenFlamingo

- 仓库：https://github.com/mlfoundations/open_flamingo
- 简介：DeepMind Flamingo 的开源复现，实现少样本交错图文理解。
- 适用：多图少样本学习、图文交错推理。

## MiniGPT-4

- 仓库：https://github.com/Vision-CAIR/MiniGPT-4
- 简介：仅用一个投影层连接视觉编码器与 LLM，复现 GPT-4 视觉对话能力。
- 适用：轻量多模态基线、教学示例。
