# 开源仓库：LLM 应用开发框架

## LangChain

- 仓库：https://github.com/langchain-ai/langchain
- 简介：LLM 应用编排事实标准，提供 LLM/工具/向量库/记忆/链的统一抽象，含 LangSmith 观测与 LangServe 部署。
- 适用：通用 LLM 应用、agent、RAG 流水线搭建。

## LlamaIndex

- 仓库：https://github.com/run-llama/llama_index
- 简介：以「数据 → 索引 → 查询」为主线的 RAG 框架，对 PDF/表格/数据库等异构数据的 ingestion 与检索抽象做得很深入。
- 适用：RAG、知识库、复杂文档问答。

## Haystack (deepset)

- 仓库：https://github.com/deepset-ai/haystack
- 简介：端到端 NLP pipeline 框架，内置 RAG / agent / 多模态组件，生产级部署能力（REST/gRPC）。
- 适用：企业知识库问答、文档检索增强。
