# 行业与趋势

> 分类：**AI 知识库** → **行业与趋势**
> 路径：`resources/knowledge/12-industry-trends`

本目录聚焦 AI 领域的**行业动态、技术前沿、产业研究**三大维度，用于跟踪 AI 技术从研究突破到产业落地的全过程。所有内容以"事件—数据—解读"的结构组织，强调时效性与可验证性。

## 子分类

| 子目录 | 主题 | 收录内容 |
|---|---|---|
| [conferences/](./conferences/) | 顶会追踪 | NeurIPS / ICML / AAAI / ACL / ICLR 关键议题、获奖论文、热门 workshop |
| [frontier-papers/](./frontier-papers/) | 前沿论文 | GPT-5、Claude 4、Gemini 3 等前沿模型技术报告深度解读 |
| [industry-reports/](./industry-reports/) | 行业报告 | Stanford AI Index、McKinsey State of AI、Gartner Hype Cycle 等权威报告 |
| [news-updates/](./news-updates/) | 新闻动态 | 模型发布、融资事件、监管政策、开源生态等近期新闻 |



## 阅读建议

1. 想了解**学术最前沿** → 从 `frontier-papers/` 开始。
2. 想了解**产业全景** → 从 `industry-reports/` 开始。
3. 想了解**近期事件** → 从 `news-updates/` 开始。
4. 想了解**会议议题分布** → 从 `conferences/` 开始。
